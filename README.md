## 프로젝트 소개

**북이온앤온**은 책을 통해 마음의 양식을 나누는 안드로이드 애플리케이션입니다.
함께 읽고, 함께 나누면 감동도 배움도 두 배가 된다는 철학을 담았습니다.

### 주요 특징

-  **독서 공유** - 읽은 책의 감동을 나누세요
-  **커뮤니티** - 같은 책을 읽은 사람들과 소통하세요
- **독서 기록** - 나만의 독서 여정을 기록하세요
- **모바일 최적화** - 언제 어디서나 편리하게 이용하세요
